# github-collab

> 写完代码不想碰 git？跟 AI 说句话就行。

你用 AI 写代码，它帮你安全地传到 GitHub——不用记命令，不会误传密码，VPN 断了也能传，版本发布全自动。

## 它帮你做什么

- **说句话就提交**："传上去""直接上传""发个版"——分支、提交说明、推送全部自动搞定
- **不会手滑传密码**：自动拦截密钥、.env、Cookie、exe、视频等不该进 git 的文件，仓库默认私有
- **VPN 断了也能传**：直连失败自动走备用通道，每传一批检测一次网络，通了立刻切回快的
- **版本发布全自动**：改了版本号提交后，自动打 tag；小版本只打标记，大版本自动发 Release
- **让别的 AI 也能看懂你的项目**：首次上传自动生成 AGENTS.md，开源协作者的 AI 读了就能上手
- **不打扰你写代码**：只有你说"提交""推送"时才介入，纯编码时安安静静

## 怎么用

| 你说 | 它做 |
|------|------|
| "建个仓库传上去" | 建仓库 → 过滤敏感文件 → 提交 → 推送 → 问你要不要公开 |
| "直接上传" | 静默检查安全 → 提交 → 推送，不建分支不走 PR |
| "走个 PR" | 建分支 → 提交 → 推送 → 建 PR → 合并后自动清理 |
| "发个版本" | 打 tag → 整理更新说明 → 发布到 GitHub |
| "VPN 断了传不上去" | 自动换备用通道继续传，不耽误事 |

```

├── README.md             # 本文件
├── LICENSE               # MIT
└── references/
    ├── agents-template.md
    ├── gh-cli-setup.md
    ├── git-operations.md
    ├── platform-commands.md
    └── skill-evolution.md
```
