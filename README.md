# github-collab

> 跟 AI 说句话就能管 GitHub：建仓库、提交代码、发版本，不用记命令；VPN 断了也能传，不会把密码、视频、exe 这些不该传的文件误传上去。

## 这是什么

一个豆包（Doubao）Skill。装上之后，你只需要跟 AI 说"帮我提交代码""建个仓库传上去""发个版本"，它会自动帮你走完整个流程——不用记 git 命令，不用担心把密码传上去，VPN 断了也能传成功。

## 你只需要说

| 你说 | 它做 |
|------|------|
| "帮我建个仓库传上去" | 建仓库 → 过滤掉不该传的文件 → 提交 → 推送 → 问你要不要公开 |
| "提交代码" | 检查改了什么 → 确认没有密码和私人文件 → 写规范的提交说明 → 推送 |
| "发个版本" | 打标签 → 整理更新内容 → 发布到 GitHub |
| "帮我公开仓库" | 自动装好需要的工具 → 引导你授权一次 → 切换为公开 |
| VPN 断了传不上去 | 自动换一条备用通道继续传，VPN 一恢复自动切回快速的通道 |

## 核心能力

- **不用记命令**：说人话就行，分支命名、提交格式、PR 流程全部自动规范
- **不会误传**：自动拦截密码、密钥、.env 等敏感文件，以及视频、exe、依赖包等不该进 git 的文件，仓库默认私有
- **VPN 断了也能传**：直连 GitHub 失败时自动走备用通道，传完一批就检测一次 VPN，通了立刻切回快的
- **需要时自动装工具**：遇到备用通道也做不了的操作（如公开仓库、上传版本附件），自动下载安装 GitHub 官方工具，引导你授权一次后长期可用
- **帮你记笔记**：解决了难题、做了重要决策时，提醒你记一笔，方便以后复盘
- **越用越好用**：遇到没覆盖的情况会自动补充规则，不用你手动改

## 安装

将本目录放到豆包 Skill 目录下：

```
<skill_root>/github-collab/
├── SKILL.md              # 核心流程（Agent 读取）
├── README.md             # 本文件（给人看）
└── references/
    ├── agents-template.md
    ├── gh-cli-setup.md
    ├── git-operations.md
    └── skill-evolution.md
```
